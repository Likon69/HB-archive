# HB Archive

My personal collection of Honorbuddy builds, gathered over the years. From the earliest WotLK-era releases through Cataclysm, MoP and WoD versions — every build I could get my hands on.

None of these are my work. Honorbuddy was developed by Apoc, raphus, highvoltz, bobby53, xanathos, chinajade and the Bossland team.
